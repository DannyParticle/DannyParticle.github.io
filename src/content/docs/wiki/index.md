# 王维诗里的MBTI 维基

「王维诗里的MBTI」是 bilibili 上一个以 MBTI 为主题、以 16personalities 的 16 型人格形象为主角进行创作的动画频道，
由王元元与维基运营。本站是它的资料维基，收录角色档案、作品设定与理论整理。

!!! info "关于这次迁移"

    本维基原托管在 Fandom（`wangweishilidembti.fandom.com`）。
    由于 Fandom 在中国大陆无法正常访问，现迁移到 GitHub Pages。
    原始导出与转换脚本都保存在仓库里，内容可随时重新生成。

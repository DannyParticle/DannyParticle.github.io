Zuan (ISTP; gender-swapped name: Zhu'an. Both names come from splitting the pinyin of 钻 (zuan) apart)

Original name: Connoisseur

Aliases: Drill Bit<small> (added on July 25, 2025)</small>

One of the main characters of the [MBTI in Wang Wei's Poems (王维诗里的MBTI)](/wiki/channel/) Channel.

<small>*————"The road on this mountain never ends; let's set off now."* (added on July 25, 2025)</small>

## Cognitive functions (based on the Beebe model)

First function (Dominant / Hero): Ti (Introverted Thinking)

Second function (Auxiliary / Parent): Se (Extraverted Sensing)

Third function (Tertiary / Eternal Child): Ni (Introverted Intuition)

Fourth function (Inferior / Anima-Animus): Fe (Extraverted Feeling)

Fifth function (Opposing / Opposing Personality): Te (Extraverted Thinking)

Sixth function (Critical / Senex or Witch): Si (Introverted Sensing)

Seventh function (Blind Spot / Trickster): Ne (Extraverted Intuition)

Eighth function (Devilish / Demon): Fi (Introverted Feeling)

## Easter eggs & trivia

- Zuan's heart always carries an electric drill and a hammer, and often appears when he is struggling inside.

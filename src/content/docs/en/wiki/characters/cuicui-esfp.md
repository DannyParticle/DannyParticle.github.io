Cuicui (ESFP; the name is a homophone of "Chui Chui". Gender-swapped name: Cui Can)

Original name: Entertainer

Aliases: Funny Girl, Maraca, Chui Chui<small> (added on July 25, 2025)</small>

One of the main characters of the [MBTI in Wang Wei's Poems (王维诗里的MBTI)](/wiki/channel/) Channel.

*<small>————"I want to feel what it's like to be lifted up by the waves!"</small>*<small> (added on July 25, 2025)</small>

## Cognitive functions (based on the Beebe model)

First function (Dominant / Hero): Se (Extraverted Sensing)

Second function (Auxiliary / Parent): Fi (Introverted Feeling)

Third function (Tertiary / Eternal Child): Te (Extraverted Thinking)

Fourth function (Inferior / Anima-Animus): Ni (Introverted Intuition)

Fifth function (Opposing / Opposing Personality): Si (Introverted Sensing)

Sixth function (Critical / Senex or Witch): Fe (Extraverted Feeling)

Seventh function (Blind Spot / Trickster): Ti (Introverted Thinking)

Eighth function (Devilish / Demon): Ne (Extraverted Intuition)

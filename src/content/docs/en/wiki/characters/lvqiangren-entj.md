Lü Qiangren (吕强人) (ENTJ; the name is a homophone of the Chinese word for "strong woman". The male version is "Lan Qiangren", a homophone of "strong man")

Original name: Commander

Aliases: Domineering CEO, Big Sister, Strong Woman<small> (added on July 25, 2025)</small>

One of the main characters of the [MBTI in Wang Wei's Poems (王维诗里的MBTI)](/wiki/channel/) Channel.

*<small>————"I've found the exit I want to carve out."</small>*<small> (added on July 25, 2025)</small>

## Cognitive functions (based on the Beebe model)

First function (Dominant / Hero): Te (Extraverted Thinking)

Second function (Auxiliary / Parent): Ni (Introverted Intuition)

Third function (Tertiary / Eternal Child): Se (Extraverted Sensing)

Fourth function (Inferior / Anima-Animus): Fi (Introverted Feeling)

Fifth function (Opposing / Opposing Personality): Ti (Introverted Thinking)

Sixth function (Critical / Senex or Witch): Ne (Extraverted Intuition)

Seventh function (Blind Spot / Trickster): Si (Introverted Sensing)

Eighth function (Devilish / Demon): Fe (Extraverted Feeling)

## Easter eggs & trivia

- Lü Qiangren is the only character with a tail ([Xiugougou (修勾勾)](/wiki/characters/xiugougou-enfp/) has one too, but it only appears occasionally).
- Lü Qiangren's demon horns are actually just decoration.

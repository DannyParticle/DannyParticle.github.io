Shutiao (舒迢) (INTP; the name is a homophone of the Chinese word for "french fries". The male version is "Ke Le", a homophone of "cola")

Original name: Logician

Aliases: AirPods Girl, Bottle, French Fries, Potion<small> (added on July 25, 2025)</small>

One of the main characters of the [MBTI in Wang Wei's Poems (王维诗里的MBTI)](/wiki/channel/) Channel.

*<small>————I wonder whether I, too, have become a speck of stardust in the universe.</small>*<small> (added on July 25, 2025)</small>

## Cognitive functions (based on the Beebe model)

First function (Dominant / Hero): Ti (Introverted Thinking)

Second function (Auxiliary / Parent): Ne (Extraverted Intuition)

Third function (Tertiary / Eternal Child): Si (Introverted Sensing)

Fourth function (Inferior / Anima-Animus): Fe (Extraverted Feeling)

Fifth function (Opposing / Opposing Personality): Te (Extraverted Thinking)

Sixth function (Critical / Senex or Witch): Ni (Introverted Intuition)

Seventh function (Blind Spot / Trickster): Se (Extraverted Sensing)

Eighth function (Devilish / Demon): Fi (Introverted Feeling)

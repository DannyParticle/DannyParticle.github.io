Mama (ISFJ; the name is a homophone of "mom". The male version is "Diemi" (迭弥), a homophone of "daddy")

Original name: Defender

Aliases: Little Nurse, Mama<small> (added on July 25, 2025)</small>

One of the main characters of the [MBTI in Wang Wei's Poems (王维诗里的MBTI)](/wiki/channel/) Channel.

*<small>————So the past does not, after all, fade like smoke.</small>*<small> (added on July 25, 2025)</small>

## Cognitive functions (based on the Beebe model)

First function (Dominant / Hero): Si (Introverted Sensing)

Second function (Auxiliary / Parent): Fe (Extraverted Feeling)

Third function (Tertiary / Eternal Child): Ti (Introverted Thinking)

Fourth function (Inferior / Anima-Animus): Ne (Extraverted Intuition)

Fifth function (Opposing / Opposing Personality): Se (Extraverted Sensing)

Sixth function (Critical / Senex or Witch): Fi (Introverted Feeling)

Seventh function (Blind Spot / Trickster): Te (Extraverted Thinking)

Eighth function (Devilish / Demon): Ni (Introverted Intuition)

## Easter eggs & trivia

- The early gender-swapped character art of the old version originally had a beard (designed after the male ISFJ on 16personalities), but it was never used.
- Mama's bag can hold anything, including a piano and a tire.
- Whenever Mama gets jealous, they tap a wooden fish non-stop.

Chizi (ESTJ; the name is a homophone of "ruler")

Original name: Executive

Aliases: Shark, Ruler, Dean of Discipline<small> (added on July 25, 2025)</small>

One of the main characters of the [MBTI in Wang Wei's Poems (王维诗里的MBTI)](/wiki/channel/) Channel.

<small>*————"Let's go, while our troubles are still asleep. Let's go, while tomorrow has not yet come."* (added on July 25, 2025)</small>

## Cognitive functions (based on the Beebe model)

First function (Dominant / Hero): Te (Extraverted Thinking)

Second function (Auxiliary / Parent): Si (Introverted Sensing)

Third function (Tertiary / Eternal Child): Ne (Extraverted Intuition)

Fourth function (Inferior / Anima-Animus): Fi (Introverted Feeling)

Fifth function (Opposing / Opposing Personality): Ti (Introverted Thinking)

Sixth function (Critical / Senex or Witch): Se (Extraverted Sensing)

Seventh function (Blind Spot / Trickster): Ni (Introverted Intuition)

Eighth function (Devilish / Demon): Fe (Extraverted Feeling)

Xiugougou (ENFP; the name comes from "happy little pup" (快乐修勾), and the male version is "Xiu Wangwang" (修望望), a homophone of "little woof-woof" (小汪汪))

Original name: Campaigner

Aliases: Happy Puppy, Xiu Gou, Little Doggy<small> (added on July 25, 2025)</small>

One of the main characters of the [MBTI in Wang Wei's Poems (王维诗里的MBTI)](/wiki/channel/) Channel.

The male and female versions of this character are sister and brother.

*<small>————Grass seeds, sunlight, half a bottle of galaxy, and a "next stop" that never runs out.</small>*<small> (added on July 25, 2025)</small>

## Cognitive functions (based on the Beebe model)

First function (Dominant / Hero): Ne (Extraverted Intuition)

Second function (Auxiliary / Parent): Fi (Introverted Feeling)

Third function (Tertiary / Eternal Child): Te (Extraverted Thinking)

Fourth function (Inferior / Anima-Animus): Si (Introverted Sensing)

Fifth function (Opposing / Opposing Personality): Ni (Introverted Intuition)

Sixth function (Critical / Senex or Witch): Fe (Extraverted Feeling)

Seventh function (Blind Spot / Trickster): Ti (Introverted Thinking)

Eighth function (Devilish / Demon): Se (Extraverted Sensing)

## Easter eggs & trivia

- Xiugougou's head and Xiu Wangwang's chest pocket carry the same flower, and it changes with their mood.
- Xiugougou is often forgetful, a nod to the fact that the inferior function of ENFPs is Si (Introverted Sensing), which leaves them unable to remember details.
- Xiugougou once missed Xiaofudie at Sanbao Station on Hangzhou Metro Line 6 because he forgot to get off the train; see the episode "【王维MBTI】16人格重逢多年未见的白月光 | cp向 | 全员向动画".

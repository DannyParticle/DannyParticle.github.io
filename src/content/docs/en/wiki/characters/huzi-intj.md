Huzi (胡紫) (INTJ; the name is a homophone of the Chinese word for "mustache")

Original name: Architect

Aliases: Ascetic Old Man, Purple Old Man, Purple Sweet Potato, Mustache<small> (added on July 25, 2025)</small>

One of the main characters of the [MBTI in Wang Wei's Poems (王维诗里的MBTI)](/wiki/channel/) Channel.

<small>*————The mountain wind blew, and everything truly became clear* (added on July 25, 2025)</small>

## Cognitive functions (based on the Beebe model)

First function (Dominant / Hero): Ni (Introverted Intuition)

Second function (Auxiliary / Parent): Te (Extraverted Thinking)

Third function (Tertiary / Eternal Child): Fi (Introverted Feeling)

Fourth function (Inferior / Anima-Animus): Se (Extraverted Sensing)

Fifth function (Opposing / Opposing Personality): Ne (Extraverted Intuition)

Sixth function (Critical / Senex or Witch): Ti (Introverted Thinking)

Seventh function (Blind Spot / Trickster): Fe (Extraverted Feeling)

Eighth function (Devilish / Demon): Si (Introverted Sensing)

## Easter eggs & trivia

- Huzi is the only character with a dedicated pet (a cat named "Little Mustache").
- The earlier version of the character had a mustache, but an online poll showed that 80% of fans were against keeping it, so the new character design moved the mustache onto the pet cat.

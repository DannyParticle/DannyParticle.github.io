Bailitouhei (INFJ; the female version is "Bailitoumo" (百里透墨); the name is a homophone of "white outside, black inside" (白里透黑))

Original name: Advocate

Nicknames: Green Old Man, Magic Old Man<small> (added on July 25, 2025)</small>

One of the main characters of the [MBTI in Wang Wei's Poems (王维诗里的MBTI)](/wiki/channel/) Channel.

*<small>————"Of all the countless sounds in this world, if you do not listen, they are merely sounds."</small>*<small> (added on July 25, 2025)</small>

## Cognitive functions (based on the Beebe model)

First function (Dominant / Hero): Ni (Introverted Intuition)

Second function (Auxiliary / Parent): Fe (Extraverted Feeling)

Third function (Tertiary / Eternal Child): Ti (Introverted Thinking)

Fourth function (Inferior / Anima-Animus): Se (Extraverted Sensing)

Fifth function (Opposing / Opposing Personality): Ne (Extraverted Intuition)

Sixth function (Critical / Senex or Witch): Fi (Introverted Feeling)

Seventh function (Blind Spot / Trickster): Te (Extraverted Thinking)

Eighth function (Devilish / Demon): Si (Introverted Sensing)

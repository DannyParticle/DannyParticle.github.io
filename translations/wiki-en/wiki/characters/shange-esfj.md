Shange (ESFJ; the name is a homophone of "Umbrella Bro". The female version is "Shanjie" (单洁), a homophone of "Umbrella Sis")

Original name: Consul

Aliases: Male Mom, Umbrella Bro<small> (added on July 25, 2025)</small>

One of the main characters of the [MBTI in Wang Wei's Poems (王维诗里的MBTI)](/wiki/channel/) Channel.

*<small>————"I will hold the string, hoping the kite dares to fly toward the sun."</small>*<small> (added on July 25, 2025)</small>

## Cognitive functions (based on the Beebe model)

First function (Dominant / Hero): Fe (Extraverted Feeling)

Second function (Auxiliary / Parent): Si (Introverted Sensing)

Third function (Tertiary / Eternal Child): Ne (Extraverted Intuition)

Fourth function (Inferior / Anima-Animus): Ti (Introverted Thinking)

Fifth function (Opposing / Opposing Personality): Fi (Introverted Feeling)

Sixth function (Critical / Senex or Witch): Se (Extraverted Sensing)

Seventh function (Blind Spot / Trickster): Ni (Introverted Intuition)

Eighth function (Devilish / Demon): Te (Extraverted Thinking)
